## 🧭 我在做什么

> 一句人话版：**我做网站、聊天工具和自动化脚本——帮人把重复的活儿交给程序干。**

<br>

### 🧩 [ToTheMoom · 资讯门户网站](https://github.com/MarmotDay/ToTheMoom)

> 一个开箱即用的网站系统，适合快速搭建内容/资讯类平台。

- 前后台完整，已经真实部署上线
- 基于 PHP，部署简单、上手快
- 适合个人或小团队快速起步一个网站

`PHP` · `门户网站` · `快速开发`

<br>

### 💬 [GolangChat · 聊天系统](https://github.com/MarmotDay/GolangChat)

> 一套完整的聊天工具，让用户之间能实时对话。

- 支持单聊、群聊
- 用户上线全网通知、昵称、聊天记录留存可查
- 基于 Go 开发，稳定、能扛住高并发

`Go` · `即时通讯` · `高并发`

<br>

### 🕷️ [spiderkitUtil · 批量采集工具](https://github.com/MarmotDay/spiderkitUtil)

> 一个"自动收集资料"的小工具，把手工一张张保存的活儿交给它。

- 一键批量下载网页上的图片、文件
- 支持多任务同时抓取，速度快
- 自动整理命名，省去手动改文件名

`Go` · `自动化` · `爬虫工具`
